프로젝트 실행 방법 (백엔드 백그라운드 + 프론트엔드)
========================================

1. 터미널 1: 백엔드 실행
   - 위치: project 루트에서 시작하는 것이 안전합니다.
       cd c:\Users\SionDK\Documents\project
   - 가상환경이 있으면 활성화:
       .\.venv\Scripts\Activate.ps1
   - 백엔드 폴더로 이동 후 실행:
       cd backend
       python -m uvicorn main:app --reload

2. 터미널 2: 프론트엔드 실행
   - 위치: frontend 폴더
   - 명령어 (일반):
     cd frontend
     flutter run
   
   - 명령어 (Chrome으로 직접 실행):
     cd frontend
     flutter run -d chrome
